Bug fixes: Two users editing a copy of the same model in their own personal place could see each other as editors. Some complex data types with references could confuse AI agents expected data type. Removed the DMN attributes labelVerticalAlignment and labelHorizontalAlignment from the DMN XML exports version 1.5 and below since some DMN runtimes from other vendors were not properly supporting these values and refused to load the model.
